# Attribution and fork scope

Perch is an unofficial, modified fork of [Vorssaint](https://github.com/vorssaint/vorssaint-utils), created by Vorssaint and its contributors. They built the original app and its features. This fork does not claim authorship of that work or endorsement by the original project.

Preetham Lokesh maintains this fork to use the app on an older Intel Mac. Modifications dated 2026-11-01 add Intel/universal builds, classic Intel sensor discovery, and an independent Perch identity. The source remains available under GPL-3.0-or-later; see LICENSE. Original copyright and license notices are retained in the source.

Perch uses `io.protopanda.perch` (developer builds: `io.protopanda.perch.dev`), its own approved bird app artwork, its own signing identity, and this fork's repository links. Its panda menu icon is rendered using the installed Apple Color Emoji font; no font is bundled, and Apple emoji artwork is not claimed as original Perch artwork. It does not install over, migrate, or remove the upstream app. Automatic self-installing updates are disabled until this fork has its own reviewed signing and update policy.

Upstream source and documentation remain in this repository for attribution and development history. Historical source filenames and internal implementation names do not imply an official upstream build. Reserved upstream artwork is not used for the Perch app icon or menu mark.

Please credit the original authors when sharing Perch. Consider supporting or starring [Vorssaint](https://github.com/vorssaint/vorssaint-utils) as well as this Intel compatibility fork.
